# Security Policy

## Supported Versions

We actively support and release security fixes for the current minor release track:

| Version | Supported          |
| :---    | :---:              |
| 0.9.x   | :white_check_mark: |
| < 0.9.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **PR Security Linter** itself (e.g. an unintended command injection vulnerability in our runners, or improper data handling), please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send your vulnerability report via email to:
📧 **minhtuanho120912@gmail.com**

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a Proof of Concept (PoC) demonstrating how to reproduce the issue.
- Any suggestions for remediation if available.

### What to Expect
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for assessing and remediating the issue.
- Once a fix is verified, a patch release will be published and credit will be given in the release notes (if desired).
